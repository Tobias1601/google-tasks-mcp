# google-tasks-mcp

Personal single-user MCP server that lets me read and manage my own Google Tasks from Claude.

## Privacy policy

This project is a private tool for one person (the owner). It accesses only the owner's own Google Tasks via the Google Tasks API. No data is collected from other users, shared with third parties, sold, or stored beyond what Google Tasks itself holds. Credentials are kept as encrypted secrets in the owner's own Cloudflare account.
